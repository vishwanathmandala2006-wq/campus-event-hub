# campus-event-hub

Campus Event Hub – DevOps Lab Project

## Continuous Integration



This project uses Jenkins to automatically validate the application

whenever changes are detected in the GitHub repository.

\## CI/CD Workflow



The Campus Event Hub project uses GitHub for source code management

and Jenkins for continuous integration.



Workflow:



GitHub → Jenkins → Automated Tests → Build Success



Jenkins checks the main branch for changes, retrieves the latest

source code, validates required project files, and runs automated

registration tests.
